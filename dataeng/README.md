# Data Engineering

This folder contains data engineering assets for the project.

Use this directory for:
- ETL/ELT pipelines and data ingestion scripts
- Data cleaning, transformation, and enrichment jobs
- Batch and streaming jobs (e.g., Spark, Flink, Airflow, dbt)
- Schema definitions and migration scripts for data warehouses/lakes
- Infrastructure-as-code or config specific to data workflows
